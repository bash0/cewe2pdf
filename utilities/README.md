# Utilities

These tools support album editing and investigation of CEWE resources.
Follow the repository's [Python environment setup](../README.md#install) before
running them.

| Utility | Purpose |
| --- | --- |
| [mcfxextract](mcfxextract/README.md) | Extract an MCFX document and all embedded media/resources without creating a PDF. |
| [clp2svg](clp2svg/README.md) | Extract SVG artwork from CEWE CLP files for inspection. |
| [fontcheck](fontcheck/README.md) | Find fonts that support particular Unicode characters and investigate missing glyphs. |
| [Content centering](contenttocenter/README.md) | Center selected pages' content horizontally in an MCF or MCFX album. |
