## Emojis

Adding emojis is difficult because of the font issues. Even if you find an emoji in a font you have access to, the size and weight will probably not match the font you are using. And if you change the point size of that one emoji character then the line height of the rest of the text will be affected. So it's best to avoid using emojis in text.

Instead, go to e.g. https://openmoji.org/library/ and download a version of the emoji which you can then insert and resize anywhere you like. You can choose svg or png. It's a bit difficult to place images inside a text area, but it is possible with a bit of jiggling.
